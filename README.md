# DevSecOps-Labs

A growing collection of practical Python scripts built to simulate security automation, access control, packet validation, and threat detection workflows.

## 🎯 Lab Objectives
* **Security Logic & Validation:** Implement conditional rules (`if`/`elif`/`else`) and boolean checks to filter unauthorized traffic.
* **Data & Telemetry Analysis:** Use input sanitization, string metrics, and mathematical operators (such as modulo `%`) to detect anomalies.
* **Automation Foundations:** Build modular, terminal-ready scripts designed for DevSecOps pipelines and edge nodes.

## 📂 Repository Structure
All standalone Python labs and security simulations are stored in the root directory. Current modules include:
* `edge_guard.py` — Edge node packet validation and modulo telemetry distribution.
* `access_control.py` — Security authorization and access control simulation.
* `zero_day.py` — Vulnerability and packet error validation.
* *(Additional security automation scripts added continuously as labs progress.)*
